# 6层FPGA电梯控制系统
## 项目概述
本项目基于 **Verilog HDL** 开发六层电梯控制器，适配 Altera DE2-115 FPGA 开发板，系统时钟 50MHz。
采用模块化分层设计，实现电梯呼梯调度、自动运行、开关门控制、到站提示、多模式管理；搭载UART串口通信，支持上位机下发指令控制电梯，同时实时回传电梯运行状态，完成人机交互。

> 开发工具：Quartus II、Modelsim、sscom
> 通信波特率：UART 115200
> 目标硬件：DE2-115

## 系统整体架构
顶层模块 `elevator_top` 仅负责模块例化与信号互联，无业务逻辑。所有功能独立封装子模块：
key_debounce 按键消抖模块
floor_detect 拨码开关解析，获取当前楼层
call_schedule 呼梯请求调度模块（同向优先调度）
elevator_ctrl 电梯主控有限状态机（项目核心）
buzzer_driver 有源蜂鸣器驱动
led_driver LED 指示灯驱动
uart_mode_comm UART 指令接收、电梯状态回传

数据流简述：
外部按键、楼层拨码采集 → 预处理（消抖/同步）→ 呼梯调度计算目标楼层 → 主控状态机控制电梯运行；
串口接收上位机指令切换电梯工作模式，并回传电梯实时状态；LED、蜂鸣器作为状态外设输出。

## 实现功能
### 基础运行功能
1. 6层楼层实时检测（板载拨码开关输入）
2. 呼梯请求锁存，支持多楼层同时呼叫
3. 同向优先电梯调度策略
4. 电梯自动到站开门、支持手动强制开关门
5. 到站蜂鸣提示（持续0.5s）
6. LED显示当前楼层、运行方向、电梯工作模式

### 四种运行模式（通过串口指令切换）
1. `AUTO`  自动运行模式
2. `MANUAL` 手动模式
3. `FIRE` 消防模式，电梯强制返回1楼
4. `REPAIR` 设备检修模式

### UART人机交互功能
1. 串口参数：115200 8N1
2. 上位机发送指令（末尾加`\r\n`）：`AUTO / MANUAL / FIRE / REPAIR`
3. 指令合法后，FPGA主动回传电梯状态字符串
    应答格式示例：`F:3 D:UP M:A D:O`
    - F：当前楼层
    - D：运行方向(UP/DOWN/STOP)
    - M：工作模式
    - D：门状态(O=开门 / C=关门)

## 仿真说明
1. 各个功能子模块独立编写Testbench单元仿真，通过波形观测时序行为；
2. 顶层`elevator_top`用于综合、布局布线与上板硬件验证；
3. **未搭建顶层系统级仿真**：系统激励复杂、仿真耗时较长，采用分模块验证方案。

## 调试遇到的问题与解决方案
1. **现象**：蜂鸣器响铃时长不稳定、偶发未到站提前触发蜂鸣
    原因：原始逻辑电平触发；外部异步输入缺少两级同步，存在毛刺干扰。
    方案：修改为上升沿单次触发；对外部异步信号增加两级寄存器同步，消除亚稳态风险。

2. **现象**：外部拨码开关、按键属于异步输入，存在亚稳态隐患
    方案：所有板载、外部输入信号增加两级同步寄存器。

3. **现象**：组合逻辑若分支不全容易生成锁存器
    方案：关键控制逻辑放置在时序always块内，所有寄存器复位赋予初始值，补全分支。

4. **现象**：UART连续字符接收容易采样出错
    方案：采用bit中点采样；区分起始位、数据位、停止位，增加停止位合法性校验。

## 硬件使用说明
1. 下载工程至DE2-115开发板；
2. 使用串口助手，波特率设置115200，发送指令控制电梯模式；
3. 拨码开关模拟楼层位置，按键模拟呼梯、手动开关门。

## 后续可优化方向
1. UART收发增加独立FIFO缓冲区，实现收发并行（当前简化为半双工）；
2. 增加指令超时机制，防止不完整指令造成缓存残留；
3. 呼梯调度算法拓展更多优化策略；
4. 增加指令CRC/奇偶校验，提升串口通信抗干扰能力；
5. 增加电梯运行超时保护机制。
